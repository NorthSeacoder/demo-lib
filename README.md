# demo-lib

WP 项目共工组件

## Features

-   vite 打包
-   支持按需加载
-   支持 test

## Usage

The template contains the following scripts:

-   `dev` - Start the development server
-   `build` - Build for production
-   `lint` - Checks your code for any linting errors
-   `test` - Run all tests
-   `test:coverage` - Run all tests with code coverage report
